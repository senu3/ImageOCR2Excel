# ImageOCR2Excel ユーザーガイド

このガイドは、読み取り範囲の編集、認識結果の確認、Excel・CSV出力など、起動後の操作を目的別に説明します。

初回セットアップと最初のExcelを作る手順は、[README](../README.md#はじめる)を参照してください。

## 作業を始める

起動時の **「開始方法を選択」** で **「新規テンプレートを作成」** を選び、同じレイアウトの画像が入ったフォルダーを指定します。

フォルダー直下の `.png`、`.jpg`、`.jpeg`、`.bmp`、`.tif`、`.tiff` がファイル名の自然順で読み込まれます。保存済みテンプレートを使う場合は、右上の **「テンプレート操作」** から **「テンプレートを読み込む」** を選びます。

この汎用版は画像内容に応じた範囲の自動検出を行いません。画像ごとに文字の位置が変わる場合は、共通して文字が収まる範囲を指定するか、レイアウト別にテンプレートを作成してください。

## 1. 範囲・列

**「1. 範囲・列」** では、画像上の読み取り範囲とExcelへ出力する単位・順序を編集します。

### Excelの行単位を選ぶ

初期値は **「画像単位（1画像につき1行）」** です。1枚に1件分の情報がある一般的な定型画像では、この設定を使用します。有効な項目が左から列として並びます。

**「セット単位（1セットにつき1行）」** は、1枚の画像内に同じ構造のデータが複数ある場合に使用します。**「セットを追加」** で同じ種類の範囲をグループ化し、セットごとに別の行へ出力します。汎用プロファイルの既定の組み合わせは1列の **「項目セット」** です。

### 読み取り範囲を編集する

画像プレビュー上で操作します。

- 何もない場所をドラッグすると、読み取り範囲を追加します。
- 範囲の内側またはラベルをドラッグすると、範囲を移動します。
- 範囲の辺や角をドラッグすると、大きさを変更します。
- 範囲またはラベルをダブルクリックすると、項目名を編集します。
- 範囲を右クリックすると、編集、複製、削除などの操作を選べます。
- マウスホイールで上下にスクロールします。`Ctrl` を押しながら回すと表示を拡大・縮小します。

直前の追加、削除、移動、サイズ変更は、`Esc` または `Ctrl+Z` で取り消せます。

### 項目と列順を整える

右側の項目一覧で、出力する内容を整えます。

- チェックを外すと、その項目を認識・出力しません。
- 鉛筆ボタン、項目名のダブルクリック、または `F2` で項目名を変更します。
- **「OCR方式」** で **「範囲全体」** または **「行切り出し」** を選びます。
- 右端のドラッグハンドル、または `Alt+↑` / `Alt+↓` で列順を変更します。
- セット単位では、ドラッグハンドルで項目を別のセットへ移動できます。**「未割当」** の項目が残っていると出力できません。

**「範囲全体」** は1行の値や短い文字列向けです。**「行切り出し」** は、複数行の本文を行ごとに検出してから読み取ります。

### テンプレートを保存・再利用する

読み取り範囲、列順、OCR方式、出力設定、基本設定はJSONテンプレートに保存されます。

- **「保存」** または `Ctrl+S`: 現在のテンプレートを保存
- **「テンプレート操作」** → **「名前を付けて保存」** または `Ctrl+Shift+S`: 別名で保存
- **「テンプレート操作」** → **「テンプレートを読み込む」** または `Ctrl+O`: 保存済みテンプレートを読み込む

未保存の変更がある状態で別のテンプレートを読み込む、またはアプリを終了すると、保存するか確認されます。

同じレイアウトで解像度だけが違う画像では、作成時の画像サイズを基準に読み取り範囲を拡大・縮小します。縦横比や部品配置が違う画像には別のテンプレートを使用してください。

## 2. 認識テスト

**「2. 認識テスト」** では、現在表示している1枚を使って出力前にOCR結果を確認します。

1. **「全項目をテスト」** を選びます。
2. 項目一覧から確認したい項目を選びます。
3. 範囲プレビューと **「認識結果」** を確認します。

1項目だけ試す場合は、項目を選んで **「選択項目をテスト」** を使用します。範囲や **「OCR方式」** を変更した後は、もう一度テストしてください。

上部の左右ボタン、または `Ctrl+←` / `Ctrl+→` で画像を切り替えられます。文字量や背景が異なる画像を数枚確認すると、範囲のずれや空の結果を見つけやすくなります。

認識結果が合わない場合は、次を順に確認します。

1. **「1. 範囲・列」** に戻り、文字全体が範囲内に入っているか確認します。
2. 複数行の文字なら、**「OCR方式」** を **「行切り出し」** にします。
3. 上部の設定ボタンから **「基本設定」** を開き、OCR言語とテキスト整形を確認します。

## 3. Excel出力

**「3. Excel出力」** では、処理対象、保存先、シートへの書き込み方法を指定します。

### 出力対象と保存先を決める

1. **「画像フォルダ」** を確認します。変更する場合は **「変更」** を選びます。
2. **「出力ファイル」** の **「選択」** から `.xlsx` の保存先を指定します。
3. 処理対象の一覧で、不要な画像のチェックを外します。**「全選択」** と **「全解除」** も使用できます。

ファイル名を選ぶと、その画像がプレビューに表示されます。

### Excelへの書き込み方を決める

初期値は、シート名 `OCR`、**「上書き」**、開始セル `A1`、ファイル名列あり、ヘッダー行ありです。

- **「シート名」**: 認識結果を書き込むシート
- **「書き込み」**: **「上書き」** または **「追記」**
- **「開始セル」**: 書き込みを始める左上のセル（例: `A1`）
- **「ファイル名列」**: 元画像のファイル名を列に含める
- **「ヘッダー行」**: 項目名の行を含める

**「追記」** では、既存シートにデータがあれば最終行の次へ追加します。空のシートまたは新しいシートでは開始セルから書き込みます。既存ファイルを **「上書き」** するときは実行前に確認画面が表示されます。

### 出力結果を確認する

設定を確認して **「Excel出力」** を選びます。処理中は画像ごとの状態が **「待機」**、**「処理中」**、**「完了」**、**「要再実行」** として表示されます。

OCRに失敗した項目や空の結果がある場合は、同じExcelファイルに `Errors` シートが作成されます。`Notices` シートは、セット出力時に除外理由などの処理通知がある場合だけ作成されます。

### 失敗画像だけを再実行する

失敗がある場合は、範囲やOCR環境を修正してから **「失敗分を再実行（件数）」** を選びます。成功済みの画像を重複させず、失敗した画像の元の行を更新します。

再実行するまでは、出力ファイル、シート名、開始セル、Excelの行単位、出力列を変更しないでください。変更した場合は、全画像を **「Excel出力」** し直します。

### CSVで保存する

Excel出力ボタン横のメニューから **「CSV形式で保存…」** を選びます。CSVではシート名、追記、開始セル、`Errors` / `Notices` シートは使用できません。失敗内容は処理結果の表示で確認してください。

## 基本設定

画面上部の設定ボタンから **「基本設定」** を開きます。

### OCR言語

初期値は **「日本語のみ」** です。画像内の文字に合わせて、**「日本語 + English」**、**「日本語のみ」**、**「English のみ」** から選びます。

### テキスト整形

**「行のつなぎ方」** の初期値は **「全角スペース」** です。複数行の結果を **「スペースなし」**、**「全角スペース」**、**「改行」** のどれで結合するか選びます。

**「半角の英数字・記号を全角に統一」** は初期状態ではオフです。設定を変えたら **「適用」** を選び、代表画像で認識テストをやり直してください。

### OCR環境

**「OCR環境」** の **「環境設定」** では、認識モデルの状態、保存先、診断ログを確認できます。

- **「再確認」**: 保存済みモデルが現在の環境で使えるか確認する
- **「変更」**: モデル保存先を変更する
- **「自動設定に戻す」**: アプリの既定の保存先へ戻す
- **「フォルダーを開く」**: 診断ログの保存先を開く

モデル保存先を変更した場合は、画面の案内に従ってアプリを再起動します。

## 主なショートカット

| キー | 操作 |
| --- | --- |
| `Ctrl+S` | テンプレートを保存 |
| `Ctrl+Shift+S` | テンプレートに名前を付けて保存 |
| `Ctrl+O` | テンプレートを読み込む |
| `Ctrl+Enter` | Excel出力 |
| `Ctrl+←` / `Ctrl+→` | 前後の画像へ移動 |
| `Alt+↑` / `Alt+↓` | 選択項目を並べ替える |
| `F2` | 選択項目の名前を変更 |
| `Esc` / `Ctrl+Z` | 直前の範囲編集を取り消す |

確認画面や設定画面が開いているときの `Esc` は、その画面の戻る操作または閉じる操作になります。

## 困ったとき

### 画像フォルダーを選んでも画像が表示されない

選んだフォルダーの直下に対応形式の画像があるか確認します。サブフォルダー内は検索しません。対応形式は `.png`、`.jpg`、`.jpeg`、`.bmp`、`.tif`、`.tiff` です。

### OCRを実行できない

右側に表示される状態に合わせて操作します。

- **「OCR未準備」**: **「準備」** → **「ダウンロードして準備」**
- **「OCRの確認が必要」**: **「確認」** → **「確認して更新」**
- **「OCR保存先に問題」**: **「保存先」** から有効なフォルダーを指定
- **「OCR実行環境が不足」**: **「修復」** からアプリを終了し、ランチャーで修復

### アプリが起動しない

プロジェクトのフォルダーでPowerShellを開き、次を実行します。

```powershell
.\run_app.ps1 --repair
```

`uv` が見つからない場合は、[uvをインストール](https://docs.astral.sh/uv/getting-started/installation/)し、PowerShellを開き直します。

### 認識結果が空になる、または文字がずれる

**「1. 範囲・列」** で範囲を確認し、**「2. 認識テスト」** をやり直します。解像度だけでなく縦横比や配置も異なる画像では、自動スケーリングで位置が合わないため、別のテンプレートを作成してください。

### 失敗分を再実行できない

前回の出力後に、出力先、シート名、開始セル、Excelの行単位、出力列を変更していないか確認します。変更している場合は、全画像を **「Excel出力」** し直します。

### 診断ログを確認したい

**「基本設定」** → **「OCR環境」** の **「環境設定」** → **「診断ログ」** → **「フォルダーを開く」** を選びます。
