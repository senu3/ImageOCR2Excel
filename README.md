# ImageOCR2Excel

同じレイアウトの画像から指定した範囲をOCRし、画像フォルダーをExcelまたはCSVの表へ変換するWindows向けアプリです。

文字認識にはPaddleOCRを標準で使用します。

## できること

- サンプル画像上で読み取り範囲を作り、再利用できるJSONテンプレートとして保存する
- 項目名、列順、OCR方式、テキスト整形を用途に合わせて調整する
- 現在の画像で認識結果を確認してから、フォルダー内の画像をまとめて処理する
- シート名、開始セル、追記・上書き、ヘッダー、ファイル名列を指定してExcelへ出力する
- OCR失敗や空の結果をExcelの `Errors` シートで確認し、失敗画像だけを再実行する

読み取り位置はテンプレート作成時の画像サイズを基準に保存されます。同じレイアウトで解像度だけが異なる画像では範囲を自動調整しますが、縦横比や配置が異なる画像には別のテンプレートを用意してください。

## はじめる

### 必要なもの

- Windows
- [uv](https://docs.astral.sh/uv/getting-started/installation/)
- 初回セットアップとOCR認識モデル取得時のインターネット接続

### インストールして起動する

1. このリポジトリを任意のフォルダーへ配置します。
2. `ImageOCR2Excel.cmd` をダブルクリックします。
3. ランチャーに **「初回セットアップ」** と表示されたら、**「セットアップを開始」** を選びます。
4. アプリに **「OCR認識モデルをダウンロード」** と表示されたら、**「ダウンロードして準備」** を選びます。

画面に **「準備完了」** と表示されれば、文字認識を使用できます。OCRを後で準備する場合は、**「今は準備せず、範囲編集へ」** を選ぶとテンプレート編集だけを先に進められます。

PowerShellから起動する場合は、プロジェクトのフォルダーで次を実行します。

```powershell
.\run_app.ps1
```

開発環境からアプリ本体を直接起動する場合は、依存関係を同期してから実行します。

```powershell
uv sync
uv run python main.py
```

### 最初のExcelを作る

この手順では、1枚の画像をExcelの1行として出力します。

1. **「開始方法を選択」** で **「新規テンプレートを作成」** を選び、同じ形式の画像が入ったフォルダーを指定します。
2. **「1. 範囲・列」** で画像上の読み取りたい場所をドラッグし、項目名を入力します。必要な列の数だけ繰り返します。
3. **「2. 認識テスト」** で **「全項目をテスト」** を選び、認識結果を確認します。
4. **「3. Excel出力」** を開き、**「出力ファイル」** の **「選択」** から保存先を指定します。
5. **「Excel出力」** を選びます。

**「完了」** と表示され、指定した場所に `.xlsx` ファイルが作成されれば完了です。既定では1行目に項目名、2行目以降に画像ごとの結果が出力されます。

## 更新する

更新後のファイルを別のフォルダーへ配置し、`ImageOCR2Excel.cmd` から起動します。ランチャーが依存関係の変更を検出すると **「アプリを更新」** を表示します。OCR認識モデル、端末設定、保存済みテンプレートはアプリデータ領域に保持されます。

新しい版の動作を確認してから、古い配置フォルダーを削除してください。

## 起動できないとき

- `uv was not found` または `uvが見つかりません` と表示される

  uvをインストールし、PowerShellまたはコマンドプロンプトを開き直してから起動します。

- アプリに **「OCR実行環境が不足」** と表示される

  **「修復」** を選び、アプリを終了してランチャーの修復を実行します。

- アプリ自体が開かない

  プロジェクトのフォルダーで次を実行します。

  ```powershell
  .\run_app.ps1 --repair
  ```

詳しい症状別の対処は、[ユーザーガイドの「困ったとき」](docs/USER_GUIDE.md#困ったとき)を参照してください。
